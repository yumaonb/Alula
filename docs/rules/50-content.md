# 50 — 内容与分类

> 读法：动 `src/content/**` 之前读本篇。内容条款（目录即分类、slug、图片路径、字段清单）见 `AGENTS.md`「开发规范」第 7 节；新增文章流程见 `docs/reference/CONTENT.md`「新增文章流程」。本篇只记规范里没有的细节。

## frontmatter 字段细节

| 字段          | 类型     | 必填 | 说明                                                                                                                      |
| ------------- | -------- | ---- | ------------------------------------------------------------------------------------------------------------------------- |
| `title`       | string   | 建议 | 缺省时显示"无标题"                                                                                                        |
| `date`        | 日期     | 必填 | 写 ISO 格式 `2026-09-06`；参与排序，缺了构建直接失败（`content.config.ts` 里是必填）                                      |
| `description` | string   | 可选 | 卡片摘要与 SEO 描述                                                                                                       |
| `image`       | string   | 可选 | 封面图，写相对本文的路径；有封面时 RSS 订阅源会额外输出 `enclosure` 缩略图                                                |
| `tags`        | string[] | 可选 | 缺省为空数组                                                                                                              |
| `pinned`      | boolean  | 可选 | 置顶，缺省 false                                                                                                          |
| `hidden`      | boolean  | 可选 | 隐藏文章，缺省 false；不进列表 / 分类页 / 标签页 / 侧栏计数 / 上下篇 / RSS / 站内搜索，页面另加 `noindex`，只有直链能访问 |

## 图片细节

- 相对路径由 `ImageWrapper.astro` 依据文章的 `basePath` 解析并做 Astro 图片优化；`http` 开头的绝对地址会被当作外链，不走优化。

## 改完必做

- 新增或改动文章后确认 `dist/` 里生成的页面数与文章数一致（验证流程见 `docs/rules/70-verify.md`）。
